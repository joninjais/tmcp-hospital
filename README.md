# TMCP Hospital WordPress Theme

ธีม **tmcp-hospital** เป็นธีมสำหรับ WordPress ที่ออกแบบมาเพื่อเว็บไซต์โรงพยาบาลหรือหน่วยงานทางการแพทย์ โดยเน้นความเรียบง่าย ใช้งานง่าย และโหลดเร็ว

## คุณสมบัติหลัก
- รองรับการแสดงผลโพสต์และบทความ
- ดีไซน์ทันสมัย เหมาะกับองค์กรทางการแพทย์
- ใช้ฟอนต์ Poppins และโทนสีสุภาพ
- โครงสร้าง HTML5 และ CSS ที่เหมาะกับ SEO
- รองรับการใช้งานกับปลั๊กอินยอดนิยม เช่น Elementor, Tabs Responsive

## โครงสร้างไฟล์หลัก
- `index.php` : หน้าแสดงรายการโพสต์/บทความ
- `header.php` : ส่วนหัวของเว็บไซต์
- `footer.php` : ส่วนท้ายของเว็บไซต์
- `style.css` : กำหนดรูปแบบการแสดงผล
- `functions.php` : ฟังก์ชันเสริมสำหรับธีม

## วิธีติดตั้ง
1. อัปโหลดโฟลเดอร์ `tmcp-hospital` ไปที่ `/wp-content/themes/`
2. เข้าเมนู "Appearance" > "Themes" ใน WordPress Admin
3. เลือก "TMCP Hospital" แล้วกด Activate

## การปรับแต่ง
- สามารถแก้ไขไฟล์ CSS หรือเพิ่มฟีเจอร์ใน `functions.php` ได้ตามต้องการ
- รองรับการปรับแต่งผ่าน Customizer

## ข้อแนะนำเพิ่มเติม
- ควรใช้ปลั๊กอินแคชและบีบอัดรูปภาพเพื่อเพิ่มความเร็ว
- อัปเดตธีมและปลั๊กอินให้เป็นเวอร์ชันล่าสุดเสมอ
